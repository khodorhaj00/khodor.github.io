# Sample and fixture files

## `Rhino_Logo.3dm`

The Rhino logo model from the three.js repository (`examples/models/3dm/Rhino_Logo.3dm`, MIT licence
like the rest of three.js). It is a genuine Rhino-saved file, which is what the synthetic fixtures are
not: saved by Rhinoceros 7 Commercial (build 2020-09-08), OpenNURBS archive version 70, units
millimetres, 5.6 MB.

| Content | Count | Layer |
|---|---|---|
| Breps, each with cached render meshes | 6 | `brep` |
| SubDs | 6 | `subd` |
| NURBS curves | 218 | `curves` |
| Text dots | 4 | `textdot` |
| Point cloud | 1 | `pointclouds` |
| Lights | 2 | `lights` |

No block definitions, no materials the viewer relies on. Expected viewer result (`docs/ARCHITECTURE.md`
§2.3): `meshes` 12 (6 Breps + 6 SubDs), `curves` 218, `unmeshed.total` 0, `units` `Millimeters`; the
Playwright harness renders it in about 0.4 s on a desktop Chromium.

## Synthetic fixtures (`backend/test/fixtures/`)

Generated by `backend/test/fixtures/make_fixtures.py` with the `rhino3dm` Python package and shared by
the backend tests (`node --test`) and the viewer harness (`app/tool/viewer_test/run.mjs`):

| File | Content | What it exercises |
|---|---|---|
| `meshes.3dm` | 48 mesh boxes on `PARTS` / `FOAM` (user string `PART_ID`), one sphere with an object colour on `REFERENCE`, one box on the invisible layer `HIDDEN`, one closed polyline, one point; mm | ordinary production file: layer colours, object colour, hidden layer, curves and points, GLB export |
| `brep_nomesh.3dm` | 2 Breps **without** render meshes (box + sphere) on `BREPS`, plus one mesh | a *Save small* / scripted file: `unmeshed.breps` 2 in the viewer, `/mesh` replaces both (`X-Meshed-Count: 2`) |
| `blocks.3dm` | one instance definition (mesh box) referenced 5 times on `BLOCKS` | block instances, nested transforms, per-instance triangle counting |

Regenerate them (the counts stay identical; object ids and bytes change, so only do this when the
generator changes):

```sh
pip install rhino3dm
cd backend/test/fixtures && python make_fixtures.py
```

The script prints the object, layer and instance-definition counts of each file it wrote. Run
`cd backend && npm test` and `cd app/tool/viewer_test && node run.mjs` afterwards; both assert the
counts listed in `docs/ARCHITECTURE.md` §2.3 and §4.3.
